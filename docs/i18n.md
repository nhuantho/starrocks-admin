# Internationalization (i18n)

The UI supports English (`en`, default) and Simplified Chinese (`zh-CN`).

## Frontend

- Library: `@ngx-translate/core` 14 with a namespaced loader (`src/app/@core/i18n/i18n.config.ts`).
- Translations live in `src/assets/i18n/<lang>/<namespace>.json`. A key `foo.bar` in
  `cluster.json` is used as `cluster.foo.bar`.
- `LanguageService` (`src/app/@core/services/language.service.ts`) picks the language
  (saved choice → browser language → `en`), stores it in `localStorage`, and sets `<html lang>`.
  The header has a language selector.
- Every HTTP request carries `Accept-Language` (added in `jwt.interceptor.ts`).

| Namespace | Scope |
| --- | --- |
| `common` | Shared words (OK, Cancel, Save…), header, `@core`, `@theme` |
| `menu` | Sidebar menu and tab titles |
| `auth` | Login, register, first-login password change |
| `cluster` | Clusters, overview, dashboard, nodes, sessions, variables |
| `sql` | SQL execution page |
| `profile` | Query Profiles and diagnostics |
| `audit` | Audit logs |
| `mv` | Materialized views |
| `sysfn` | System function cards |
| `system` | Users, roles, organizations, user settings |

### Usage

- Template: `{{ 'cluster.overview.title' | translate }}`, with params
  `{{ 'cluster.nodes.offline' | translate: { count: n } }}` and `"Offline: {{count}}"` in JSON.
- TypeScript: inject `TranslateService` and call `translate.instant('key', params)`.
  Values computed once at init (chart options, column configs, card lists) must be rebuilt on
  `translate.onLangChange`.
- Add every key to **both** `en` and `zh-CN` files.
- Check key parity and unknown keys with `npm run i18n:check` (in `frontend/`).

## Backend

Handlers read the request language with the `Lang` extractor (`backend/src/utils/i18n.rs`) from
`Accept-Language`. English is the default; `zh*` selects Chinese. Use `lang.pick("中文", "English")`
for user-facing text.
